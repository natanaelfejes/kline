# kline documentation

kline is open-source Renault K-line diagnostics (ISO 9141-2, KWP2000 / ISO 14230) over an FTDI
KKL cable. Start with the [project README](../README.md) for what it does and how to install it.

| Document | Read it when you want to |
|---|---|
| [protocol.md](protocol.md) | understand K-line, 5-baud init, fast init and KWP2000 framing, or check an exact byte or timing value |
| [cli.md](cli.md) | look up a command, option or exit code, or do the first test at the car |
| [platforms.md](platforms.md) | set up the cable on Linux, macOS or Windows, or understand timing precision |
| [architecture.md](architecture.md) | find your way around the code |
| [sim.md](sim.md) | test without a car, or know what the simulator does not prove |
| [spec-semantics.md](spec-semantics.md) | know exactly how a DDT2000 definition is decoded |
| [SAFETY.md](SAFETY.md) | know what kline will and will not send to an ECU |
| [CONTRIBUTING.md](CONTRIBUTING.md) | send a pull request or a capture from your car |
